# Hands tracking using the Kalman filter

This project demonstrates hand tracking in a video sequence using the Kalman filter.

The project contains a Jupyter notebook with the mathematical model, simulated data, Kalman filter implementation, visualizations, uncertainty intervals, and real-data processing. Real hand measurements are collected using a webcam detector based on MediaPipe hand landmarker.

## Repository structure

```text
.
├── README.md
├── hand_landmarker.task
├── hand_tracking_kalman_filter.ipynb
├── hands_tracker.py
└── tracking_data.csv
```

## Files

- `hand_tracking_kalman_filter.ipynb`  
  Main notebook containing the model description, simulation, Kalman filter implementation, plots, real-data analysis, and conclusion.

- `hands_tracker.py`  
  Python script for collecting real hand-tracking measurements from a webcam.

- `tracking_data.csv`  
  Example real measurement data generated by `hands_tracker.py`.

- `hand_landmarker.task`  
  MediaPipe model file required by the hand detector.

## Requirements

Install the required Python packages:

```bash
pip install numpy pandas matplotlib opencv-python mediapipe
```

## Running the detector

To collect new webcam measurements, run:

```bash
python3 hands_tracker.py
```

or choose a specific camera index:

```bash
python3 hands_tracker.py --camera 0
python3 hands_tracker.py --camera 1
```

Controls:

```text
q  quit
r  reset Kalman trackers
```

The detector saves measurements to:

```text
tracking_data.csv
```

The CSV file contains:

```text
timestamp, obj_type, meas_x, meas_y, pred_x, pred_y
```

where `obj_type` is either `hand_left` or `hand_right`.

## Running the notebook

Open:

```text
hand_tracking_kalman_filter.ipynb
```

and run all cells from top to bottom.

The notebook includes:

- discrete state-space model,
- simulated hand motion,
- noisy measurements,
- Kalman filter implementation,
- comparison with the true simulated state,
- 95% uncertainty intervals,
- multi-step prediction,
- processing of real webcam data.

## Notes

The detector script uses MediaPipe only to obtain hand position measurements. The main Kalman filter implementation and analysis are done in the Jupyter notebook.
